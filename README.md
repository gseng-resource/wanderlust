# Wanderlust

- `index.html` / `index.zh.html`: home page (English / Simplified Chinese)
- `about.html` / `about.zh.html`: how the research is done: sources, reliability, ratings, budget method, check dates

Research lives in the private trip dockets; a trip is published here only when the owner asks, and can be unpublished.
